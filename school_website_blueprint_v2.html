Key Features — Phase 1
6 focused, high-impact features for the first launch
📣
Live Notice Board
Scrolling ticker on the home page + full notices listing, filterable by category and date. Admin can post in seconds.
🌐
Multilingual (Hindi / English)
One-click language toggle in the header. All pages, menus, and notices switch between Hindi and English instantly.
🖼️
Media Gallery
Album-based photo & video gallery with lazy loading. Albums organised by year and event category for easy browsing.
📅
Events Calendar
Monthly calendar view showing school holidays, exams, and events. Exportable to Google Calendar & iOS Calendar.
📱
Mobile-First Design
Fully responsive layout built for phones first — most parents browse on mobile. Touch-friendly nav and fast load times.
📝
Online Admission Form
Multi-step application form with document upload support. Applicants receive a confirmation reference number on submission.

Usage Guide
Sunburst / Gold
Hero sections, CTA buttons, nav highlights, logo background — the dominant attention colour
Deep Orange
Hover states, section dividers, icon accents, active link underlines
Night Blue
All body text, headings, footer background — high contrast against warm tones
Slate Gray
Sub-headings, captions, meta text, icon labels — secondary text layer
Warm Off-White
Page background, card fills — warmer alternative to harsh white
Cream Tint
Feature card backgrounds, notice board highlight, admission section tint

Recommended Tech Stack
Lean, modern, and budget-friendly — matched to Phase 1 scope
Frontend
Next.js 14
React framework — SSR for SEO, fast static pages, great for school sites
Tailwind CSS
Utility-first CSS — rapid build, easy to maintain brand colours
next-intl
Hindi ⇄ English i18n — JSON translation files, URL-based locale switching
Framer Motion
Notice board ticker, gallery transitions, scroll animations
FullCalendar
Events calendar component — monthly view, Google Calendar export
Backend / API
Node.js
API routes within Next.js — no separate server needed
Prisma ORM
Type-safe DB access — notices, events, admissions tables
PostgreSQL
Reliable relational DB — stores notices, applications, gallery metadata
NextAuth.js
Admin-only login — email/password, protected CMS routes
CMS & Media
Sanity.io
Headless CMS — editors update text, news, notices without code
Cloudinary
Gallery image/video hosting — auto-optimisation, album CDN delivery
TipTap
Rich text editor for admin — notice body, news posts, About page
Hosting & Forms
Vercel
Deploy frontend — global CDN, free tier, auto deploys on push
Supabase
Postgres DB + file storage — free tier sufficient for Phase 1
Resend / Email
Admission confirmation emails — reference number + acknowledgement
